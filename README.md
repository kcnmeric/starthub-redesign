# Start Hub Digital Website Redesign

A modern and responsive one-page website redesign concept for **Start Hub Digital**, built with HTML and CSS.

This project focuses on improving the visual structure, navigation experience, responsive layout, and overall presentation of a digital agency website.

## Live Demo

[View Live Website](https://kcnmeric.github.io/starthub-redesign/)

## Project Purpose

The goal of this project was to redesign an existing digital agency website into a cleaner, more modern, and user-friendly landing page.

The redesign keeps the original brand identity while improving:

- Visual hierarchy
- Section structure
- Responsive navigation
- Call-to-action placement
- Mobile usability
- Overall landing page flow

## Features

- Responsive one-page landing page
- Sticky gradient navbar
- Mobile hamburger menu
- Dropdown navigation
- Hero section with call-to-action buttons
- Services section
- About section
- Why choose us section
- Process section
- Stats section
- Contact call-to-action
- Footer with social media links

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Git & GitHub
- GitHub Pages

## Sections

### Header & Navigation

The header includes the original brand logo, desktop dropdown navigation, language links, and a mobile hamburger menu for smaller screens.

### Hero Section

The hero section introduces the brand with a strong headline, supporting text, and clear call-to-action buttons.

### Services Section

This section presents the main digital services such as Google Ads management, mobile app development, web design, and social media management.

### About Section

The about section explains the brand’s role as a strategic digital solution partner.

### Why Choose Us

This section highlights the key reasons to work with the agency, including modern design, result-oriented thinking, and end-to-end process management.

### Process Section

A simple four-step process explains how a project moves from analysis to launch.

### Contact CTA

The final call-to-action encourages visitors to get in touch and request a proposal.

## What I Learned

While building this project, I practiced:

- Creating a real-world landing page structure
- Improving an existing website concept
- Building responsive layouts with Flexbox and CSS Grid
- Creating a mobile hamburger menu using HTML and CSS
- Organizing CSS for larger landing pages
- Using Git and GitHub for version control
- Publishing a project with GitHub Pages
